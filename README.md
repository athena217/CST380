# CST380: Mobile & Ubiquitous Computing (CSUMB)

Labs and projects from CodePath's IOS102 (Intermediate iOS Development),
taken through California State University, Monterey Bay in Spring 2026.
Units 1 to 3 use UIKit and Storyboards. Units 4 to 6 use SwiftUI.

## UIKit (Units 1 to 3)

| Folder | What it is |
|---|---|
| lab-task-squirrel | Chore list app: attach a photo to each task and see on a map where it was taken (MapKit, PHPicker) |
| project1 | Scavenger hunt app: complete photo tasks and view each photo's location on a map |
| lab-insta-parse | Instagram-style app with sign up, login, and a photo feed backed by Parse |
| project2 | BeReal clone, part 1: post a photo and view friends' posts using a Parse backend |
| lab_3 | Instaparse, part 2: camera capture and more complex post filtering |
| project3 | BeReal clone, part 2: persistent login, camera photos, and extra BeReal features |

## SwiftUI (Units 4 to 6)

| Folder | What it is |
|---|---|
| lab4-flashcard | Flashcard app with card flip animations and swipe gestures |
| Memory-Game | Memory matching game |
| Parks | REST client for the National Parks Service API, filtered by state, with detail and map views |
| Project5-TriviaGame | Trivia game that fetches questions from the Open Trivia Database |
| FireChat | Real-time chat app using Firebase Firestore and authentication |
| Project6-TranslateMe | Translation app using the MyMemory REST API, with results saved in Firebase |

## Tech
Swift, UIKit, SwiftUI, MapKit, Parse, Firebase Firestore, REST APIs, Xcode
